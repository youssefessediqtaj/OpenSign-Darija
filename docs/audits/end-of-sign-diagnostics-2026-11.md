# End-of-sign diagnostics — 2026-11-02

The previously deployed implementation confirmed the reported failure mechanism: a no-hand frame resets visible-hand end stability even if pose remains detected. If hands disappear before the 420 ms stability and post-roll finish and do not return, that path must reach the six-second timeout. High segment hand coverage measures the whole attempt and does not establish a valid ending. The supplied summary does not contain frame-by-frame evidence, so this mechanism is not proven as the cause of that particular physical attempt.

Visible-hand completion retains the 0.045 per-frame normalized mean-distance energy, 420 ms stability and three post-roll frames. A separate conservative disappearance heuristic requires at least eight usable frames after capture starts; an earlier tracked hand with a visible pose wrist in the signing zone; monotonic detector timestamps with no capture gap over 250 ms; no hands detected; both shoulders and wrists finite, visible and within the image; both wrists below the existing shoulder-relative rest boundary; and at least one tracked wrist at least 0.12 normalized image heights below its earlier signing height. The independently observed pose must remain at rest with energy at or below 0.045 for 700 ms. Any violation resets the rest interval; a detector gap disqualifies this disappearance path for the attempt. These new 0.12/700 ms/250 ms safeguards are conservative engineering heuristics, not calibrated physical-camera results. Pose evidence can still be wrong, and a signer can move out of view while a sign is incomplete. Missing pose wrists, ambiguous occlusion or continued movement remain fail-closed. The existing duration, usable-frame, quality, payload and experimental-model validations still apply.

The local diagnostics panel reports current state, motion, tracking, durations and the latest completion, rejection and request status; detailed attempt JSON remains in memory only. The manual mode is disabled by default, requires the existing local diagnostics authorization, and requires explicit start and stop. It shares the same six-second timeout, source-frame minimum, payload checks, model compatibility checks and experimental response handling; it does not speak or use a legacy endpoint. A manual stop expresses the operator's boundary, not scientific confirmation of a complete sign. No media is recorded by these diagnostics.

Physical camera testing is still required to measure false completion, missed boundaries and the effect of wrist visibility and jitter; the available deterministic fixtures do not validate linguistic or model accuracy. No model, dataset, schema or model registry changes were made for this task.
