# COLORS_V1 inference isolation — 2026-11-02

The recognition workspace sends landmarks only to `/api/v1/recognitions/colors-experimental`; it has no speech call or word-recognition request. Sign Again aborts the request, advances the session guard, clears the candidate and resets the segmenter while keeping the camera stream. The gateway and inference `/word` routes remain for separate historical operation when color mode is disabled; in color mode they return 404. The inference model loader skips the legacy ONNX loader in color mode. The color route calls only the explicitly configured color registry and has no fallback.

The loader verifies the configured version, model and dataset identities, current manifest fingerprint, schema, exact nine-label order and mapping version, experimental and calibration status, artifact hashes, training report, ONNX input and nine-score output shapes. Its cache keys include registry and manifest hashes. Missing or incompatible artifacts return `MODEL_NOT_READY`; malformed runtime scores return `INCOMPATIBLE_MODEL_OUTPUT`. Both blue variants are assigned to the same semantic class in the dataset configuration. These safeguards do not establish accuracy or calibration.

The gateway response schema positively restricts candidates and diagnostic rankings to the nine color labels, requires the color model identity, excludes semantic accepted labels and variants, and rejects incompatible responses with a fixed `INCOMPATIBLE_MODEL_OUTPUT` error without echoing upstream values. The browser rejects unsupported candidates and diagnostic labels, requires experimental uncalibrated responses, and never speaks a candidate. The diagnostic interface is opt-in, token-gated and local; it displays only in-memory metadata and uncalibrated scores.

The separate legacy endpoints are intentionally retained for historical mode and must not be exposed as a fallback in color mode. The local recovery Compose override selects the provisional registry and preserves the pre-existing external Docker network; the standard local override now requires an explicit registry filename and version. Cached artifacts are checked again before use. Gateway model-load failures use the structured `MODEL_NOT_READY` HTTP 503 error contract. This report concerns local diagnostics, not production activation or real-world recognition accuracy.
