# CNDP and public-opening readiness checklist

No item is marked complete because evidence has not been supplied in this
workspace. Attach evidence and obtain controller approval before changing a box.

- [ ] Identify and document the legal data controller.
- [ ] Finalize the exact purpose.
- [ ] Define all recipient categories and collaborator access.
- [ ] Approve retention by record status and dataset-release state.
- [ ] Define access, rectification, opposition, withdrawal, and deletion handling.
- [ ] Approve identity verification for rights requests.
- [ ] Approve versioned consent evidence.
- [ ] Approve the French notice and qualified Arabic translation.
- [ ] Determine declaration versus prior authorization with the CNDP or qualified
  Moroccan legal counsel.
- [ ] Obtain and configure the real receipt or authorization reference.
- [ ] Verify processor contracts where applicable.
- [ ] Verify storage location, processors, and international transfers.
- [ ] Verify each reference video’s rights and sign correctness.
- [ ] Approve a security and operational readiness review.
- [ ] Record explicit controller approval for public opening.
- [ ] Only then set both `CONTRIBUTION_REFERENCE_VIDEOS_APPROVED=true` and
  `CONTRIBUTION_COLLECTION_ENABLED=true`.

The software validates that the configured procedure is either `declaration` or
`prior_authorization`; it deliberately does not choose which procedure applies.

## Official working references

Re-check these CNDP sources immediately before approval because procedures and
forms can change:

- [Notifier un traitement](https://www.cndp.ma/notifier-un-traitement/) explains
  the default declaration route, categories requiring prior authorization, and
  the separate treatment of international transfers.
- [Conditions de conformité](https://www.cndp.ma/conditions/) summarizes purpose
  limitation, proportionality, security, processors, notification, and transfer
  obligations.
- [Mentions types](https://www.cndp.ma/mentions-types/) provides the CNDP’s
  collection-notice pattern for controller, purpose, procedure reference,
  recipients, and rights contact.

These links support the checklist; they do not determine the correct procedure
for this project. That determination and the real CNDP evidence remain
**UNCONFIRMED**.
